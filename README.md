# Silambarasan C — Premium Portfolio

A responsive single-page portfolio built with **HTML, CSS, and vanilla JavaScript**. The visual direction uses a dark navy technical aesthetic, cyan-blue accents, subtle glass panels, responsive layouts, and accessible navigation.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — theme, layout, responsive styles
- `script.js` — mobile navigation, active section highlighting, current year
- `assets/` — optional images you add later

## Run locally
Open `index.html` in a browser. For the simplest mobile workflow, extract the ZIP and open the file in your browser or QuickEdit preview.

## Publish with GitHub Pages
1. Create a repository named `silambarasan-portfolio` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before publishing — personalise these items
1. **Email:** replace `silambarasan@gmail.com` in `index.html` with your real professional email.
2. **Project links:** replace the placeholder GitHub profile links in the project cards with each exact repository URL. Project descriptions are written as categories until specific repository URLs are supplied.
3. **Experience:** verify role names and dates against your official offer letters/certificates before public posting.
4. **Resume:** if you want a resume button, add your final PDF as `resume.pdf` in the repository and add a link such as `<a href="resume.pdf" download>Download resume</a>`.
5. **Photo:** the hero currently uses a CSS/code illustration rather than a generated portrait. You can replace it with a real professional photo if desired.

## Tech
HTML5 · CSS3 · Vanilla JavaScript · Lucide icons (CDN) · Google Fonts (CDN)
